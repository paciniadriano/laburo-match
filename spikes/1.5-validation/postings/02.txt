Requerimientos del cargo

[description]
- Mínimo 4 años de experiencia profesional en desarrollo de software, utilizando las tecnologías requeridas.

- Experiencia sólida en arquitectura y desarrollo de microservicios y APIs RESTful.
- Experiencia avanzada con bases de datos SQL y NoSQL, especialmente PostgreSQL y MongoDB.

- Experiencia práctica con Docker y Kubernetes.
- Experiencia trabajando con AWS, especialmente API Gateway, Lambda, S3 y SQS.

[projects]
Angecom es una empresa que combina estrategia, diseño y tecnología para desarrollar soluciones digitales innovadoras que impulsan el crecimiento de sus clientes. Sus servicios incluyen desarrollo de aplicaciones web, automatización de campañas, marketing digital y soluciones tecnológicas para diferentes industrias.
Buscamos un Backend Developer Java con experiencia en el desarrollo de aplicaciones robustas, escalables y de alto rendimiento, utilizando Java, Spring Boot, microservicios y tecnologías cloud.
Formarás parte de un entorno colaborativo, trabajando con equipos multidisciplinarios en el diseño, desarrollo y optimización de servicios backend y APIs. Tendrás la oportunidad de participar en soluciones tecnológicas de alto impacto, aplicando buenas prácticas de arquitectura, calidad de código y mejora continua.

[functions]
- Diseñar, desarrollar y mantener aplicaciones y servicios backend utilizando Java 8 o superior y Spring Boot.
- Desarrollar y optimizar microservicios y APIs RESTful, garantizando escalabilidad, rendimiento e integración entre sistemas.
- Diseñar, implementar y optimizar bases de datos SQL y NoSQL, especialmente PostgreSQL y MongoDB.
- Aplicar principios SOLID, arquitectura limpia y buenas prácticas de desarrollo para asegurar código mantenible y reutilizable.
- Implementar y mantener aplicaciones contenerizadas utilizando Docker y Kubernetes.
- Desplegar y administrar servicios backend en AWS, incluyendo API Gateway, Lambda, S3 y SQS.
- Identificar y resolver problemas técnicos relacionados con rendimiento, disponibilidad e integración.
- Colaborar con equipos multidisciplinarios para desarrollar soluciones confiables, escalables y alineadas con las necesidades del negocio.
